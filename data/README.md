# Kaggriculture Dataset Directory

This directory stores raw, sample, and cleaned datasets for the **Kaggriculture Agricultural Simulation Analysis & Strategy Platform**.

## Official Kaggle Dataset
- **Competition Dataset URL:** [https://www.kaggle.com/datasets/kaggle/kaggriculture-episodes-2026-09-08](https://www.kaggle.com/datasets/kaggle/kaggriculture-episodes-2026-09-08)
- **Description:** Turn-based multi-agent agricultural simulation episodes featuring 30-day farming seasons (720 turns), dynamic crop markets, livestock management, land quadrants, and agent actions.

## Downloading via Kaggle API
If you have the Kaggle CLI configured on your computer:
```bash
kaggle datasets download -d kaggle/kaggriculture-episodes-2026-09-08 --unzip -p data/
```
Alternatively, upload your downloaded `.zip`, `.csv`, `.json`, `.jsonl`, or `.parquet` files directly via the **Data Management** page in the application.

## Provided Sample Files
- `kaggriculture_sample_episodes.csv`: 120 realistic simulation episodes between 8 benchmark agents, featuring crops harvested, market revenue, land expansion, livestock counts, and final scores. Clearly labeled as sample data.
- `kaggriculture_sample_replays.json`: Turn-by-turn granular action sequence replays with rewards and actions (planting, watering, fertilizing, harvesting, market sales, livestock care).

## Canonical Schema
| Column | Type | Description |
|---|---|---|
| `episode_id` | String | Unique match identifier |
| `agent_a` | String | Name/identifier of Agent A |
| `agent_b` | String | Name/identifier of Agent B |
| `score_a` | Float | Final score (bank balance) of Agent A |
| `score_b` | Float | Final score (bank balance) of Agent B |
| `winner` | String | Winning agent name or 'Tie' |
| `total_turns` | Integer | Simulation duration in turns (default: 720) |
| `season_day` | Integer | Simulation days (default: 30) |
| `actions_a_count` | Integer | Total recorded actions taken by Agent A |
| `actions_b_count` | Integer | Total recorded actions taken by Agent B |
| `crops_harvested_a` | Integer | Number of crops harvested by Agent A |
| `crops_harvested_b` | Integer | Number of crops harvested by Agent B |
| `market_sales_a` | Float | Total market revenue generated by Agent A |
| `market_sales_b` | Float | Total market revenue generated by Agent B |
| `land_quadrants_a` | Integer | Land quadrants owned by Agent A |
| `land_quadrants_b` | Integer | Land quadrants owned by Agent B |
| `livestock_count_a` | Integer | Livestock animals raised by Agent A |
| `livestock_count_b` | Integer | Livestock animals raised by Agent B |
| `status` | String | Simulation termination state (`FINISHED`, etc.) |
